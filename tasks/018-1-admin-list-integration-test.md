# Task 018-1: 관리자 목록 통합 테스트

## 개요

Playwright MCP를 사용하여 관리자 글 목록 페이지의 전체 흐름을 E2E 테스트한다. 사이드바 내비게이션, 필터 탭, 글 상세 이동, 모바일 반응형, 다크 모드 적용 상태를 검증한다.

## 관련 파일

- `app/dashboard/layout.tsx`: 사이드바 레이아웃
- `app/dashboard/posts/page.tsx`: 글 목록 테이블 페이지
- `components/dashboard/posts-table.tsx`: 테이블 컴포넌트
- `components/layout/dashboard-sidebar.tsx`: 사이드바 컴포넌트

## 수락 기준

- [ ] `/dashboard/posts` 접근 → 글 목록 테이블 정상 렌더링
- [ ] 초안/발행됨 상태 필터 탭 동작 검증
- [ ] 발행됨 글 제목 클릭 → 블로그 상세 페이지 이동 검증
- [ ] 사이드바 토글 (모바일) 동작 확인
- [ ] 다크 모드 적용 상태에서 시각 검증
- [ ] 빈 상태/에러 상태 핸들링 확인

## 구현 단계

### 단계 1: 개발 서버 기동 확인

- [ ] `npm run dev` (port 3000) 실행 확인

### 단계 2: 사이드바 내비게이션 테스트

- [ ] `/dashboard` 접근 → 사이드바 표시 확인 (snapshot)
- [ ] 사이드바 "글 목록" 클릭 → `/dashboard/posts` 이동 확인
- [ ] 활성 메뉴 항목 하이라이트 확인

### 단계 3: 글 목록 테이블 테스트

- [ ] 테이블 렌더링: 제목/카테고리/발행일/상태/액션 컬럼 표시 확인
- [ ] 발행됨 글 뱃지 색상 확인
- [ ] 초안 글 뱃지 색상 확인 (secondary/outline)

### 단계 4: 필터 탭 동작 테스트

- [ ] "발행됨" 탭 클릭 → 초안 글 숨김 확인
- [ ] "초안" 탭 클릭 → 발행됨 글 숨김 확인
- [ ] "전체" 탭 클릭 → 전체 글 표시 확인

### 단계 5: 글 상세 이동 테스트

- [ ] 발행됨 글 제목 링크 클릭 → `/posts/[slug]` 이동 확인
- [ ] 올바른 slug로 상세 페이지 렌더링 확인

### 단계 6: 모바일 반응형 테스트

- [ ] 뷰포트 375px 설정
- [ ] SidebarTrigger(햄버거) 버튼 표시 확인
- [ ] 버튼 클릭 → Sheet 사이드바 열기
- [ ] 카드 형태 목록 표시 확인 (테이블 대신)

### 단계 7: 다크 모드 테스트

- [ ] 다크 모드 전환 후 `/dashboard/posts` 스냅샷
- [ ] 테이블/뱃지/사이드바 다크 모드 색상 확인
