# Task 021: 관리자 글 목록 테이블에 공유 메뉴 통합

## 개요

Task 018에서 구현한 관리자 글 목록 테이블의 "액션" 컬럼에 `ShareLinkMenu` 컴포넌트를 삽입한다. 각 행의 글 정보(slug, title, status)를 props로 전달하고, 모바일 카드 폴백 뷰에도 동일한 공유 메뉴를 배치한다. 다크/라이트 모드 양쪽에서 드롭다운과 토스트 가독성을 검증한다.

## 관련 파일

- `components/dashboard/posts-table.tsx`: 액션 컬럼에 ShareLinkMenu 삽입
- `components/dashboard/share-link-menu.tsx`: Task 020에서 구현한 공유 메뉴
- `app/dashboard/posts/page.tsx`: 페이지 (변경 불필요 예상)

## 수락 기준

- [ ] 테이블 "액션" 컬럼에 `ShareLinkMenu` 삽입
- [ ] 각 행의 `slug`, `title`, `status` props 올바르게 전달
- [ ] 발행됨 글: 공유 메뉴 활성화, 드롭다운 정상 동작
- [ ] 초안 글: 공유 메뉴 비활성화
- [ ] 모바일 카드 폴백 뷰에도 공유 메뉴 배치
- [ ] 라이트/다크 모드 양쪽에서 드롭다운/토스트 가독성 확인

## 구현 단계

### 단계 1: posts-table.tsx에 ShareLinkMenu 통합

- [ ] `ShareLinkMenu` 임포트 추가
- [ ] 테이블 "액션" `TableCell`에 `<ShareLinkMenu slug={post.slug} title={post.title} status={post.status} />` 삽입
- [ ] 액션 컬럼 너비 조정 (너무 넓거나 좁지 않도록)

### 단계 2: 모바일 카드 폴백에 공유 메뉴 추가

- [ ] 모바일 카드 컴포넌트에 `ShareLinkMenu` 배치
- [ ] 카드 우측 상단 또는 하단 영역에 위치 조정

### 단계 3: 개발 서버 통합 확인

- [ ] 테이블 각 행에 공유 아이콘 버튼 표시 확인
- [ ] 발행됨 글 → 드롭다운 열기 → 복사 동작 확인
- [ ] 초안 글 → 버튼 비활성화 확인
- [ ] 모바일(375px) → 카드 공유 버튼 확인
- [ ] 다크 모드 전환 후 드롭다운/토스트 시각 확인
