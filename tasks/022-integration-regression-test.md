# Task 022: 통합 회귀 테스트 및 접근성 재검증

## 개요

Phase 1~3의 모든 기능(다크 모드, 관리자 레이아웃, 공유 링크)이 통합된 상태에서 종합 E2E 테스트를 수행한다. 3개 뷰포트에서 시각 회귀를 점검하고, 키보드 내비게이션과 WCAG 2.1 AA 색상 대비를 재검증한다. MVP에서 통과했던 핵심 시나리오도 함께 회귀 확인한다.

## 관련 파일

- `app/page.tsx`: 홈 페이지
- `app/posts/[slug]/page.tsx`: 글 상세 페이지
- `app/categories/page.tsx`, `app/categories/[name]/page.tsx`: 카테고리 페이지
- `app/dashboard/layout.tsx`, `app/dashboard/posts/page.tsx`: 관리자 페이지
- `components/layout/navbar.tsx`: Navbar + 다크 모드 토글
- `components/dashboard/share-link-menu.tsx`: 공유 메뉴

## 수락 기준

- [ ] 전체 E2E 플로우: 다크 모드 토글 → 관리자 진입 → 글 목록 → 공유 링크 복사
- [ ] 3개 뷰포트(375px / 768px / 1280px) 시각 회귀 없음
- [ ] 사이드바/네비/테이블/공유 메뉴 키보드 내비게이션 정상
- [ ] 다크 모드 포함 WCAG 2.1 AA 색상 대비 4.5:1 이상 유지
- [ ] MVP 핵심 시나리오 회귀 없음 (홈→상세→뒤로가기, 카테고리, 404)

## 구현 단계

### 단계 1: 통합 E2E 플로우 테스트

- [ ] 홈(`/`) 접근 → 라이트 모드 기본 상태 확인
- [ ] Navbar 다크 모드 토글 클릭 → 다크 모드 전환 확인
- [ ] `/dashboard/posts` 접근 → 사이드바 + 글 목록 렌더링 확인
- [ ] 필터 탭 동작 확인 (발행됨/초안)
- [ ] 공유 버튼 클릭 → 링크 복사 → Toast 확인
- [ ] 새로고침 → 다크 모드 유지 확인

### 단계 2: 3개 뷰포트 시각 회귀 점검

- [ ] **375px (모바일)**:
  - 홈 카드 1열 레이아웃
  - 모바일 Navbar 햄버거 메뉴
  - 관리자 Sheet 사이드바
  - 카드 형태 목록
- [ ] **768px (태블릿)**:
  - 홈 카드 2열 레이아웃
  - 관리자 사이드바 표시 여부 확인
- [ ] **1280px (데스크톱)**:
  - 홈 카드 3열 레이아웃
  - 관리자 사이드바 고정 표시

### 단계 3: 키보드 내비게이션 검증

- [ ] Navbar 링크 Tab 키 이동
- [ ] 다크 모드 토글 Enter 키 동작
- [ ] 사이드바 메뉴 Tab/Enter 키 이동
- [ ] 테이블 공유 버튼 Tab 접근 → Enter → 드롭다운 열기
- [ ] 드롭다운 항목 방향키 이동

### 단계 4: 접근성 색상 대비 재검증

- [ ] 라이트 모드: background/foreground 4.5:1 이상
- [ ] 다크 모드: background/foreground 4.5:1 이상
- [ ] 뱃지(발행됨/초안) 라이트/다크 양쪽 대비 확인
- [ ] 사이드바 메뉴 텍스트 대비 확인

### 단계 5: MVP 회귀 시나리오

- [ ] 홈(`/`) → 글 카드 클릭 → 상세(`/posts/[slug]`) → 브라우저 뒤로가기 → 홈
- [ ] 카테고리 탭 클릭 → 필터링 동작 확인
- [ ] 존재하지 않는 경로(`/not-exist`) → 404 페이지 렌더링
- [ ] 검색 기능 동작 확인

## 테스트 체크리스트

- [ ] 전체 플로우 E2E (다크 모드 → 관리자 → 공유) 오류 없음
- [ ] 모바일(375px) 시각 회귀 없음
- [ ] 태블릿(768px) 시각 회귀 없음
- [ ] 데스크톱(1280px) 시각 회귀 없음
- [ ] 키보드 내비게이션 전체 흐름 이상 없음
- [ ] WCAG 2.1 AA 색상 대비 라이트/다크 양쪽 통과
- [ ] MVP 핵심 시나리오 회귀 없음
